  1 # Woche 01 - Git Learning Log

  ## Lernziel

  ---

  - Grundlagen von Git verstehen und sicher anwenden
  - Staging, Restore, Branch-Workflow, Merge/Rebase und Konfliktlösung beherrschen
  - Offizielle Cheat-Sheet, Pro Git und GUI-Tools (Git für Windows / Visual Studio) kennenlernen

  ## Inhalte

  ---

  - Grundlegende Befehle: git init, git status, git add, git commit, git log, git diff
  - Staging & Restore: git add -p, git restore, git reset (Unterschiede und Einsatzfälle)
  - Branch-Workflow: git branch, git checkout / git switch, Feature-Branches anlegen
  - Merge vs. Rebase: git merge, git rebase, Fast-Forward, Vor- und Nachteile
  - Konflikte lösen: Erkennung, manuelles Auflösen, Einsatz von GUI-Tools und oh-my-git
  - Ressourcen: offizielles Git Cheat-Sheet, Pro Git (Buch), Übungen mit oh-my-git, Git für Windows, Visual Studio GUI

  ## Praxis

  ---

  - Mit oh-my-git interaktive Visualisierung des Repos genutzt, um Commit-Historie besser zu verstehen
  - Mit Visual Studio Git GUI ausprobiert

  ## Erkenntnisse

  ---

  - Die Staging-Area ist nützlich für saubere, fokussierte Commits
  - Rebase erzeugt eine saubere Historie, sollte aber bei geteilten Branches mit Vorsicht verwendet werden
  - Merge ist oft einfacher und sicherer für gemeinsame Branches
  - GUI-Tools vereinfachen Konfliktauflösung, CLI-Befehle geben tiefere Kontrolle

  ## Probleme

  ---

  - Anfangs Unsicherheit, wann Rebase statt Merge sinnvoll ist
  - Merge-Konflikte traten auf — Workflow zum sauberen Lösen noch nicht vollständig automatisiert
